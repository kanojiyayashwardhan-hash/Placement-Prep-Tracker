# Launchpad — Placement Prep Tracker

A polished, responsive placement preparation dashboard built with HTML, CSS, and vanilla JavaScript. It helps students turn career goals into daily actions and monitor their progress.

## Features
- Dashboard with task counts, completion percentage, study streak, and skill readiness
- Create, complete, search, filter, and delete tasks
- Task categories, priorities, optional due dates, and notes
- Editable skill matrix for DSA, programming, core CS, projects, aptitude, communication, interviews, and web development
- Four-stage learning roadmap with one-click task creation
- Daily journal for a win, challenge, and next step
- Recent reflection history and automatic browser-local persistence
- Dark mode, responsive mobile navigation, accessible control labels, and confirmation prompts
- No framework, package installation, or backend required

## Files
`index.html` — page structure  
`style.css` — responsive layout and visual design  
`app.js` — task, skill, roadmap, reflection, and storage logic  
`README.md` — project guide  
`LICENSE` — MIT license

## Run locally
1. Extract the ZIP or clone the repository.
2. Open `index.html` in a modern browser.
3. Add tasks and update your skill levels.

You may open the folder in VS Code and use Live Server if installed; a local server is optional.

## Technology
HTML5, CSS3, vanilla JavaScript (ES6+), and browser `localStorage`.

## Privacy and limitations
Data stays in local storage in the current browser; it is not sent to a server. Clearing browser site data can erase saved progress. The app is a client-side portfolio project and does not sync across devices.

## Future improvements
JSON backup/restore, calendar planning, company-specific interview tracks, Pomodoro timer, historical charts, and optional authenticated sync.
